## 1. メインページ（新しい `index.html`）

### 見た目（Nouns ポップ）

- 背景は白か薄いグレー。Nouns 公式サイトのような明るさで、ドット絵が映えるようにする
- 差し色は ⌐◨-◨ の赤メガネの赤と、Nouns らしい原色
- スマホで見やすいことを優先する（ゲームはスマホで遊ばれることが多い）

### 構成（上から順に）

**① ヘッダー**
- 左: ロゴ「naoblock」＋副題「⌐◨-◨ 咲耶GAMES & ナノブロック」
- 右: なし（月見台の「満月まで」の位置。今回は空けておく）

**② ヒーロー**
- 見出し: **naoblockへようこそ**
- 一言: **咲耶GAMES・ナノブロック・Nouns ⌐◨-◨**

**③ ゲームカード（横スクロール）**
- 月見台のトレカのように、縦長カードを横に並べる。スマホでは横スワイプ
- 各カードは **サムネ画像＋タイトルだけ**（シンプル）。カード全体をタップするとゲームが開く
- サムネは各ゲームの OGP 画像をそのまま使う
- 咲耶インベーダーには **「NEW」** の印をつける

| 順 | タイトル（表示） | URL | サムネ |
|---|---|---|---|
| 1 | 咲耶インベーダー（NEW） | https://invaders.naoblock.jp/ | https://invaders.naoblock.jp/ogp.png |
| 2 | 咲耶ディグ | https://dig.naoblock.jp/ | https://dig.naoblock.jp/ogp.png |
| 3 | 咲耶ジャンプバグ | https://jumpbug.naoblock.jp/ | https://jumpbug.naoblock.jp/ogp.png |
| 4 | 咲耶Nounラリー | https://rally.naoblock.jp/ | https://rally.naoblock.jp/ogp.png |
| 5 | 咲耶スクランブル | https://sakuya.naoblock.jp/ | https://sakuya.naoblock.jp/ogp.png |

（並びは新しい順。なおなおが別の順を希望したら直す）
- OGP 画像は横長なので、縦長カードに収めるときは `object-fit: cover` で切り抜く。キャラが切れる場合は、なおなおに確認する

**④ 総合ランキング**
- ゲームカードの下にセクションを置き、sakuya-kit の `mountOverallRanking` で埋め込む

```html
<div id="board"></div>
<script type="module">
  import { mountOverallRanking } from "https://cdn.jsdelivr.net/gh/naonao1971/sakuya-kit@0.2.0/kit.js";
  mountOverallRanking(document.getElementById("board"), {
    gasUrl: "https://script.google.com/macros/s/AKfycby-UoKAfHw4eBULVb37tQzwPEhNm65B_HUktd9Sh0ZxMdOdmnRHdub0NeeXUCAqg8bG/exec",
    limit: 10,
  });
</script>
```
- 5作が共通で使っているランキングGAS（`?game=scramble|rally|jumpbug` で作品別に切り替え）
- kit のランキングの見た目が Nouns ポップの配色と合わない場合は、ページ側の CSS で合わせる（kit 本体は触らない）
- 1作目のインベーダーとディグがこのGASの集計に入っているかは、実際に表示して確認する
