# naoblock.jp パイロット 修正メモ 01（2026-10-08）

`docs/手順書_メインページ改修.md` で作ったパイロット（コミット 272e5d6 時点）を、スマホ幅 375px と PC幅 1366px で確認した結果の修正依頼。
リンク・コンソールエラー・アーカイブの見るだけ化は問題なし。直すのは次の2点。

---

## 修正A: スマホではランキングを5位までにする

- 今は10位まで出していて、スマホだとランキングだけで画面の半分近くを使い、下のリンクまでが遠い
- **スマホ幅（〜599px）では5位まで、PC幅では10位まで** にする
- やり方はどちらでもよい:
  - `mountOverallRanking` の `limit` を `matchMedia("(max-width: 599px)")` で 5 / 10 に切り替える
  - または `limit: 10` のまま、スマホ幅だけ CSS で6位以降を隠す（`#board .sk-lb-list > li:nth-child(n+6) { display: none; }` など）
- kit 本体（sakuya-kit）は触らない

## 修正B: PCではゲームカード5枚を横スクロールなしで並べる

- 今は PC幅 1366px でも5枚目（咲耶スクランブル）が右端で切れている
- **PC幅（960px〜）では5枚がスクロールなしで1列に収まる** ようにする（カード幅を少し縮める、または grid で5等分）
- スマホ幅は今の横スワイプのままでよい
